# test — test plans and results

Each module's bench tests are listed in its own README. This folder holds results
(CSV logs, plots, photos, short write-ups) so they can go into the PRD, status presentation,
and final report.

Suggested layout: `test/<module>/<YYYY-MM-DD>-<what>.md` plus data files.

## System-level tests (final demo)

- [ ] Robot turns toward user when tone starts
- [ ] Follows along a path with turns at ~1 m
- [ ] Stops when user stops
- [ ] Ignores a second person without the phone
- [ ] Stops when tone ends or user leaves range
